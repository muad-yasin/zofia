# docs/

Durable, substantive reference documentation — real, measured facts a session would
otherwise have to re-derive, not build-order tracking (that's `HANDOFF.md`/`PROGRESS.md`
at the repo root) and not judgment-call history (`DECISIONS.md`). A doc belongs here if
losing it would mean re-measuring something, not just re-reading a decision.

- `field-availability.md` — HANDOFF.md item 1's nine-field matrix, resolved from Claude
  Code's own docs, the owner's real statusline script, and the 2026-09-22 live capture
  against real sessions. The reference every corner-pane field's provenance string points
  back to.
