# Code of conduct

This project is small, and it should be a pleasant place to ask a question or propose a
change.

- Be kind and assume good intent. Criticise code and ideas, not people.
- No harassment, insults, discrimination, sexual content or personal attacks, in any
  form, toward anyone.
- Respect people's time and privacy. Do not post other people's private information,
  and do not post your own session data without removing what is private.
- Stay on topic in issues and pull requests.

This applies in the issue tracker, pull requests, discussions and anywhere you speak for
the project.

**If something goes wrong,** report it privately to the maintainer through the
repository's private reporting channel (see `SECURITY.md`; mark the report as a conduct
matter), or through the contact on the maintainer's GitHub profile. The maintainer may
edit or remove comments, lock threads, and block people who break these rules, and will
keep reports confidential.
